# Music_Store_Analysis-SQL
SQL-based business analysis project using a Music Store database to answer real-world business questions through data querying and insights generation.
## Tools
- PostgreSQL
- PgAdmin4
- Relational Database Design
## Overview

This project demonstrates the use of SQL for business analysis using a Music Store database.

The objective was to answer key business questions related to customer behavior, sales performance, employee effectiveness, and revenue generation through SQL queries and data exploration.
## Business Questions Addressed

- Who are the top spending customers?
- Which music genres generate the most revenue?
- Which countries contribute the highest sales?
- Which employees support the most customers?
- Which artists and albums perform best?
- What are the most popular tracks?
## Skills Demonstrated

- SQL Querying
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Aggregate Functions
- Window Functions
- Data Analysis
- Business Intelligence
- Relational Database Concepts
